## Project Structure
- `index.html`: Home & Featured Movie Discovery Page
- `top-rated.html`: IMDb Top Rated Movies Leaderboard Chart
- `movie-detail.html`: Movie Details, Cast, Synopsis & Interactive User Reviews
- `watchlist.html`: User Personal Watchlist & Saved Ratings
- `seo-audit.html`: Built-in On-Page SEO Audit & JSON-LD Structured Data Inspector
- `robots.txt`: Search engine crawler directives
- `sitemap.xml`: Canonical XML Sitemap for search indexing
- `assets/`: Optimized movie posters and hero banners
